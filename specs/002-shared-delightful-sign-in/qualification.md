# Qualification requirements

Status: **Not run.** These are acceptance requirements for a later approved implementation, not completed tests or authorization to add/run implementation tests. Source inspection is recorded in [research](research.md).

Use two consumers representing Finance and Clipper, independent browser origins/storage and different Jazz app IDs. Use private sentinel records and an unauthorized control identity. Record SDK/provider/registry versions, configuration, environment and real persistence/acceptance evidence for each result; redact credentials. No production user data is required.

Identity qualification must name the exact Jazz release and supported admission path. The earlier
alpha.59 package observations and newer upstream backend-auth source are separate evidence sets,
not proof of compatibility. Resolve the version/integration choice before executing dependent rows.
Q-01–13 and Q-19–20 cover identity/admission; Q-14–18 additionally gate a later, separately approved
Clipper publication slice. Publication qualification does not gate Finance identity-only adoption.
